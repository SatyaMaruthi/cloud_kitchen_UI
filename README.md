# cloud-kitchen-UI

React frontend for Home Food & Subscription Marketplace.

## Run
1. Install dependencies:
   - Preferred on Windows PowerShell policy-restricted systems: `install-deps.bat`
   - Or: `npm install`
2. Start app:
   - Preferred: `run-dev.bat`
   - Or: `npm run dev`
3. Ensure backend is running at `http://localhost:8080`
